# Lieder scanned-pair alignment rebuild

The historical corpus is not safe to train or evaluate against:

- `extract_stage2_pairs.py` paired scan and MuseScore systems by ordinal position;
- MuseScore can introduce extra line breaks, so one scan line may span several
  reference systems and every later ordinal pair can shift;
- `recover_excluded_pairs.py` used a recognizer match as the label boundary and
  could write only the recognized subset of a larger crop;
- those recovered labels were generated by the same upstream model used in the
  comparison benchmark.

The replacement path is deliberately model-independent:

1. `compare_bar_counts.py` counts physical measures as supported interior barline
   clusters plus one. Edge closures, isolated stems, and narrow illustration
   detections do not consume score music.
   Each recount shard must write `--failed-out` and `--coverage-out`; any failed
   score is a failed shard, not a partial success. After rows are merged,
   `align_lieder_systems.py --require-score-ids EXPECTED_IDS` requires exact
   score-ID coverage before it writes an alignment.
2. `align_lieder_systems.py` aligns the two complete score sequences with
    one-to-one, one-to-many, many-to-one, and many-to-many moves. Small counter
   errors may anchor the path but are quarantined; only exact, globally
   unambiguous assignments with an independently certified crop boundary are
   emitted. In particular, one scan crop may safely cover several reference lines,
   but a multi-scan group whose total alone matches must not invent the internal
   scan-to-measure cuts: it is marked `boundary_ambiguous`.
3. `build_clean_stage2_pairs.py` slices the source MusicXML using those explicit
   ranges. It cannot read the recovered manifest as input and copies that manifest
   to quarantine without deleting its files.
4. `audit_clean_stage2_pairs.py` verifies provenance, file/sidecar presence,
   aligned bar spans, duplicates, and zero overlap with recovered stems.
5. `split_pairs_by_score.py` creates stable score-disjoint train and validation
   candidate manifests. Validation remains a *candidate* set until its labels pass
   manual review.

The instance-side artifacts live under `/workspace/b0/lieder-rebuild/`. The old
files remain available with dated quarantine names. Do not quote a rebuilt vocal
benchmark until the 100-item stratified review set in
`docs/writeups/review-data/alignment/` has been adjudicated and any failed stratum
has been expanded or removed.
