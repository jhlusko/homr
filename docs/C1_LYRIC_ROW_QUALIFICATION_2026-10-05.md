Frozen normalization uses Unicode NFC/casefold, standard apostrophes, removes whitespace and layout connectors (`-`, `_`, em/en dash, middle dot), and preserves accents/other punctuation. Character error is edit distance over each row, summed over408 normalized reference characters. OCR regions are assigned by geometric center in pre-recorded non-overlapping row rectangles, sorted left-to-right. Reference text never selects, reorders, corrects or prompts predictions. Empty rows count their full missing text. Unassigned page regions are not treated as lyric false positives; precision and note/word/syllable ownership are unmeasured.
